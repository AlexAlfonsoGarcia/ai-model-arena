# /add-provider command

## Purpose
Add a new AI provider.

## Workflow
1. Identify provider.
2. Inspect abstraction.
3. Inspect registry.
4. Inspect existing providers.
5. Inspect environment configuration.
6. Consult current official provider documentation when necessary.
7. Implement provider.
8. Add configuration.
9. Add error handling.
10. Add mocked tests.
11. Register provider.
12. Update documentation.
13. Run tests.
14. Run lint.
15. Run build.

## Important Note
Do not modify unrelated providers.
