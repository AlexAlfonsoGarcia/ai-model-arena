# /project-status command

## Purpose
Provide an accurate snapshot of project health.

## Inspection Areas
* Current Git branch.
* Git status.
* Current development phase.
* Completed features.
* Missing features.
* Tests.
* Lint.
* Build.
* Known issues.
* Technical debt.
* Architecture.
* Security.

## Output Format
```text
PROJECT STATUS

Current Phase:
...

Completed:
...

In Progress:
...

Missing:
...

Tests:
...

Lint:
...

Build:
...

Architecture:
...

Security:
...

Next Recommended Action:
...
```

## Important Note
Do not modify code.
