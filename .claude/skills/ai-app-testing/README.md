# AI Application Testing Skill

## Purpose
Cover testing strategies for AI applications.

## Covered Areas
* Deterministic unit tests.
* Provider mocking.
* API route testing.
* Failure simulation.
* Rate-limit simulation.
* Timeout simulation.
* Partial provider failures.
* Loading states.
* Error states.
* Response normalization.
* Token usage.
* Cost calculations.

## Important Rule
Never make real AI API calls during automated tests.
