# AI Provider Integration Skill

## Purpose
Teach Claude how to add and maintain AI providers.

## Topics
* Provider abstraction.
* Provider registry.
* Model configuration.
* SDK integration.
* Environment variables.
* Error normalization.
* Token usage.
* Latency.
* Cost calculation.
* Provider limitations.
* Mocking.
* Testing.
* Documentation.

## Standard Workflow
1. Inspect provider abstraction.
2. Inspect provider registry.
3. Inspect environment configuration.
4. Implement provider.
5. Normalize response.
6. Normalize errors.
7. Add tests.
8. Register provider.
9. Update documentation.
10. Validate.

## Note
Do not modify unrelated providers.
