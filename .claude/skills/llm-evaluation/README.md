# LLM Evaluation Skill

## Purpose
Prepare the project for future LLM evaluation functionality.

## Topics
* LLM-as-a-Judge.
* Evaluation criteria.
* Pairwise comparison.
* Rubric-based evaluation.
* Bias.
* Position bias.
* Model bias.
* Judge reliability.
* Structured outputs.
* Reproducibility.
* Human evaluation.
* Automated evaluation.

## Important Principle
An LLM judge must never be treated as objective ground truth.

Clearly distinguish:
* Model-generated score.
* Human score.
* Heuristic metric.

## Potential Evaluation Criteria
* Correctness.
* Relevance.
* Clarity.
* Completeness.
* Conciseness.

## Note
Do not implement AI Judge in the MVP.
